# Wingman: simple setup

1. Make a free account at github.com and click **New repository**. Name it `wingman`, set it to **Public**, tick "Add a README", click Create.
2. Unzip this download. Open the folder so you can see the files inside (index.html, app.js, ...).
3. In your repo click **Add file → Upload files**. Select ALL the files inside the folder and drag them onto the page. Do not drag the folder itself.
4. Click **Commit changes**. Check the repo now shows `index.html` in its main list, not inside another folder.
5. Go to **Settings → Pages**. Under Build and deployment pick **Deploy from a branch**, branch `main`, folder `/ (root)`, click Save.
6. Wait 2 minutes. Your app is at `https://YOUR-USERNAME.github.io/wingman/`
7. Open `https://YOUR-USERNAME.github.io/wingman/check.html`. Every line should show a green tick.
8. On your phone open the app link in Chrome, tap the ⋮ menu, then **Install app**.
9. Open Wingman, tap ⚙️, paste your Anthropic API key (console.anthropic.com), tap Save.

To share it, send friends the link from step 6. They repeat step 8 and 9 with their own key.
